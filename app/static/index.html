Instalar o conectar la extensión

La dirección se obtiene de esta pestaña y permanece en Chrome; no se publica ni se envía a ningún servicio externo.

Cargando paquete…
  1. Descarga, descomprime e instala el ZIP desde chrome://extensions usando Cargar descomprimida.
  2. Mantén esta aplicación abierta y genera el código temporal.
  3. Pulsa una vez el icono de xarchive: la extensión reconocerá esta dirección privada.
  4. Pega el código y confirma Emparejar. Las siguientes sincronizaciones se iniciarán desde aquí.
